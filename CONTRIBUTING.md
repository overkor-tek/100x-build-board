# Contributing

Welcome. This is dead simple.

## The 7 lanes (pick one)
- **P0-clean-repo** — carve a clean public code repo (unblocks P1/P2/P3)
- **P1-widgets** — make the cockpit widgets reliable
- **P2-araya-voice** — fix ARAYA'''s voice + brain
- **P3-file-viewer** — finish the file preview
- **P4-chat** — chat consolidation *(on hold — a decision is pending)*
- **P5-store** — make one offer sell
- **P6-harness** — the test loop that makes everything else testable

Filter the [Issues](../../issues) by label to see a lane.

## How to help (the whole process)
1. Pick an issue. Comment **"I'''ll take this."**
2. Fork, build it, open a **Pull Request.**
3. We review and merge. That'''s it.

## The one rule
Small, working, verified. One thing at a time.

## Safety
This board and its repos never contain secrets or private/legal files. If you ever see one, stop and report it — do not share it.
