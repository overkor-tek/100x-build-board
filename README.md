# 100X Build Board

Real projects you can pick up and help build. No Discord, no meetings, no gatekeeper — just code.

## How to help (30 seconds)
1. Look at the **[Issues](../../issues)** — each one is a real task: *here is what we want.*
2. Comment on the one you want: *"I will take this."*
3. Build it, open a **Pull Request.** That is the whole process.

## What this is
[100xbuilder.io](https://100xbuilder.io) / **ARAYA** — an AI assistant living in a widget dashboard. The chat works; the widgets need hands. Pick a card and jump in.

## The one rule
Small, working, verified. One thing at a time.
